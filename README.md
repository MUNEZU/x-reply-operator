# X Reply Operator

面向日本本土读者的 X 回复助手，作为 Codex skill 使用。

## 两个阶段

1. **找帖**：读取当前 X 讨论，筛选最多三个值得回复的机会，提供原帖链接、可见互动数据和切入理由，等待用户选择。
2. **改回复**：根据选中的原帖和用户提供的中文观点，整理成自然、易懂、可复制的日语回复。

## 使用原则

- 先理解原帖，一个回复只讲一个重点。
- 保留用户立场，不编造经历、数据或使用效果。
- 检查会话内已展示候选和可见本人回复，避免重复推荐。
- 只读取、分析和准备草稿，不发布、不填入编辑器、不进行平台互动。
- 不默认调用外部模型、子代理或付费服务。

## 安装

将本仓库的内容放到 `~/.codex/skills/x-reply-operator/`，保留目录结构。需要可用的浏览或搜索工具才能读取 X；登录状态或访问权限不足时，助手会说明缺口。

## 使用示例

```text
$x-reply-operator 找三条日本职场或 AI 使用困扰的帖子。
```

```text
$x-reply-operator 回复这条帖子：[链接]
我的观点是：[中文想法或真实经历]
```
